\section{Panoramica}
\paragraph{Cos'è un Runtime Environment?}

Il runtime è l'ambiente in cui il codice viene eseguito. Contiene tutto ciò di cui il codice ha bisogno per funzionare,
gestisce le risorse del sistema, la memoria, l'input/output e le operazioni di rete.

In JavaScript, il runtime è composto da un motore JavaScript, le APIs e un'event loop. Il motore JavaScript è il cuore del runtime, che esegue il codice JavaScript. L'API Web fornisce funzionalità aggiuntive per interagire con il browser, come l'accesso al DOM e le richieste di rete. L'event loop è responsabile di gestire l'esecuzione del codice asincrono e delle callback.


\color{red}\subsection{Il JavaScript Engine su browser: V8}\color{black}
\color{orange} 
Ogni browser ha il proprio JavaScript Engine, che implementa lo standard ECMAScript, quindi ognuna delle componenti presentate di seguito ha una propria implementazione specifica per ogni browser.
In particolare, nel corso della tesi prenderemo come riferimento il motore JavaScript V8, sviluppato da Google per il browser Chrome, che al momento della stesura è considerato il più veloce e performante JavaScript engine, ed è inoltre utilizzato anche dal framework NodeJs.
