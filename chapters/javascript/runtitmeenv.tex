\chapter{JavaScript Runtime Environment}

\section{Panoramica}
\paragraph{Cos'è un Runtime Environment?}

Il runtime è l'ambiente in cui il codice viene eseguito. Contiene tutto ciò di cui il codice ha bisogno per funzionare,
gestisce le risorse del sistema, la memoria, l'input/output e le operazioni di rete.

In JavaScript, il runtime è composto da un motore JavaScript,
un'API Web e un'event loop. Il motore JavaScript è il cuore del runtime, che esegue il codice JavaScript. L'API Web
fornisce funzionalità aggiuntive per interagire con il browser, come l'accesso al DOM e le richieste di rete. L'event
loop è responsabile di gestire l'esecuzione del codice asincrono e delle callback.
