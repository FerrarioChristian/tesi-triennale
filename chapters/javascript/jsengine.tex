\section{JavaScript Engine}

Ogni browser ha il proprio JavaScript Engine, che implementa lo standard ECMAScript.
Il JavaScript Engine è il cuore del JavaScript Runtime Environment.
Quando viene scritto del codice JavaScript, esso non viene esguito direttamente dall'hadware del computer,
ma passa attraverso il JavaScript Engine, che lo traduce in istruzioni che il computer può eseguire.
\color{red}Questo processo avviene in tre fasi:
\begin{enumerate}
    \item Parsing: il codice sorgente viene analizzato e trasformato in un Abstract Syntax Tree (AST).
    \item Compilation: l'AST viene tradotto in bytecode, che è un insieme di istruzioni che il computer può eseguire.
    \item Esecuzione: il bytecode viene eseguito dal motore JavaScript.
\end{enumerate}
