\section{Server Side Rendering (SSR)}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{architectures/SSR.png}
    \caption{Processo di rendering lato server (SSR)}
    \label{fig:SSR}
\end{figure}

Il SSR, o rendering lato server, è una tecnica di rendering alternativa in cui il server genera una pagina HTML
completamente renderizzata per ogni richiesta e la invia al client.\\ 
Nel SSR, il server gestisce sia il rendering che i processi di recupero dati, assicurando che il client riceva una pagina completa e pronta per la visualizzazione.\\
Nella figura \ref{fig:SSR} è mostrato il processo di rendering lato server.

\color{red}
Esempio di SSR:
Consideriamo un sito Web di e-commerce con vari elenchi di prodotti. Con SSR, quando un utente visita la pagina di
un prodotto, il server esegue il rendering dell'HTML completo, incluse le informazioni sul prodotto, le immagini e i
dati rilevanti. Ciò garantisce che l'utente veda immediatamente l'intera pagina, indipendentemente dalla potenza di
elaborazione del dispositivo o dalla velocità di Internet.
